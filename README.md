## 香港的"大带宽"，刻度比内地机房低得多

## 端口带宽不等于保证带宽，这是最容易踩的坑

官网写的"1Gbps VirtIO Port""2Gbps VirtIO Port"，指的是端口速率上限，不是保证带宽。

共享带宽的逻辑是概率统计：一条 1Gbps 出口分给几十台 VPS，低谷时大家都能跑满；一旦有用户在持续大流量下载，或者同网段被 DDoS，池子被抢空，其他人就开始丢包卡顿。真正的独享带宽会在配置单里写明 Dedicated Bandwidth、Guaranteed Bandwidth 或 CIR，GoMami 卖的是前者。

## 只计出站流量，这条规则比多送 1TB 更值钱

GoMami 官方文档写得很明确：只对出站流量计费，入站完全免费。

这意味着标称 5TB 的套餐，能承载的是 5TB 的用户下载量，而服务器主动从外部拉取的数据不花钱。对比双向计费的商家，同样写 5TB，实际可用量只有一半。对建站、文件分发、视频点播这类下载为主的业务，单向计费的含金量确实比多给 1TB 流量高。

反过来，如果你的业务是大量入站流量——镜像同步、备份回传、外部数据抓取——这条规则对你没什么额外好处，选套餐时按实际出站需求估就行。

## 三网优化，优化的是回程那一段

GoMami 在亚洲节点的结构是"去程主线 + 回程 CN2 / 9929 / CMIN2 精品"，洛杉矶节点做三网双向精品。电信对应 163/CN2，联通对应 10099/9929，移动对应 CMI/CMIN2。

回程决定国内用户从你的服务器下载资源的速度，所以对建站够用；如果你需要大量上传，去程质量才是瓶颈，而亚洲节点的去程走的是主线，不保证全程精品。

按同一份第三方测评的结论，分运营商看：

- **电信**：香港 ≈ 日本 > 新加坡，三个地区都稳
- **联通**：香港 > 日本 > 新加坡，新加坡上行断流比较明显
- **移动**：新加坡 > 日本 ≈ 香港，香港和日本的移动上行都被 QoS 压着

测评者的原话是"如果不需要大量的上传数据（直播），只是下载数据如看视频等，那其实三个地区都很猛，主推 HK"。这句话基本概括了香港节点的适用边界。

## 官网没重点写、但会影响你使用的几件事

**600 Gbps 防护是付费附加项。** 官网首页写的是"up to 600 Gbps mitigation capacity"，很容易被读成"每个套餐都送 600G 防护"。官方文档的分层写得很清楚：默认是 best-effort 基础清洗，免费包含；600 Gbps 专业清洗属于付费加购。当攻击规模影响到同网段其他客户时，IP 会被自动黑洞 30–60 分钟，自动解除，人工无法干预——黑洞期间该 IP 的所有进出流量全部丢弃。

**付款方式支持三种：** 信用卡（Stripe）、支付宝（Stripe Alipay）、加密货币。对国内用户来说支付宝这一项比较关键，不用折腾外币卡。

**退款窗口是 24 小时，不是 7 天。** 激活后 24 小时内可申请全额退款，仅限首次购买、每用户一次，续费订单不适用。不退款的情形还包括：因违反 ToS 被终止的服务、已使用的账户余额、因 DDoS 被黑洞的 IP。退款获批后实例和数据立即永久删除，申请前先备份。到账时间：支付宝 1–3 个工作日，信用卡 5–10 个工作日。

这个窗口够你跑一轮 iperf3 和 traceroute，测一下自己所在地区的实际带宽，但不够做一周的观察。

**到期当天就停，没有宽限期。** 到期日服务器立即暂停，逾期 5 天终止，数据可能无法恢复。想避免中断，可以预充账户余额做自动续费。

**流量超额不扣费，但会限速。** 官方文档只说"可能被限速，具体政策取决于产品规格"，重置时间按计费周期算。Forge 独立服务器是例外，超额按 $0.06/GB 计费。

**升降配要开工单。** 控制面板里没有自助改配的入口，需要提交工单由客服处理。

**长期满载 CPU 会被限速。** 官方文档把这种情况归为 noisy neighbor，持续高负载影响同节点其他用户时可能被降频。拿它当长期满载的编译机不合适。

**能用支付宝付款吗？**
